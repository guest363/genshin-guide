# Витрина играбельных персонажей Genshin Impact

Исследование живых витрин: как показать архив, историю, таланты и гайд без стены текста. Продукт — русскоязычный, мобильный, не клон HoYoWiki.

Дата сбора: 19 сентября 2026. Живой HTML `wiki.hoyolab.com` без JavaScript пустой (см. ниже). Карточка персонажа сверена по официальному API HoYoWiki и индексу поисковика.

---

## 1. Цель и аудитория

**Одна задача экрана.** Человек открывает архив, находит персонажа за 10 секунд и за 3 минуты понимает: кто это, как играет, чем экипировать.

**Кто читает**

- Игрок, который только выбил персонажа и хочет «с чего начать».
- Игрок, который сравнивает двух крио-мечников перед круткой.
- Читатель лора, которому не нужна таблица на 14 уровней таланта.

**Что продукт не делает**

- Не энциклопедия всех материалов, озвучки и дней рождения.
- Не калькулятор урона.
- Не клон HoYoWiki, Prydwen или Honey Hunter.

**Критерий успеха.** С телефона: фильтр «Крио + меч» → карточка Аяки → шаг «роль» гайда без прокрутки километра.

## 2. Что на самом деле делают HoYoWiki aggregate и карточка

### 2.1. Живой HTML — пустая оболочка

Прямой запрос `https://wiki.hoyolab.com/pc/genshin/aggregate/character?filter_ids=` и `https://wiki.hoyolab.com/pc/genshin/entry/10624` отдаёт Nuxt-оболочку с заголовком «Welcome to HoYoWiki!». Тело — спиннер `.wiki-loading` на фоне `#3b4354`. Контент рисует JavaScript.

Факты из оболочки:

- Мобильная вёрстка: `UI_WIDTH = 390`, пересчёт `rem` только на путях `/m/`.
- Viewport: `user-scalable=no` — не копировать: ломает увеличение текста.
- Мета: «This is the database co-built by HoYoLAB editors and players~».
- Предзагрузка API: `sg-wiki-api.hoyolab.com`, `bbs-api-os.hoyolab.com`.

Источник: HTML страниц на 19 сентября 2026.

### 2.2. Архив персонажей (aggregate)

Рабочий URL в индексе: [Character Archive](https://wiki.hoyolab.com/pc/genshin/aggregate/2?lang=en-us). Список живёт в `POST https://sg-wiki-api.hoyolab.com/hoyowiki/genshin/wapi/get_entry_page_list` с `menu_id: "2"`.

На 19 сентября 2026 API вернул **130** карточек. Порядок — от новых к старым: Vodyanitsa, Vesna, Traveler (Cryo)… Аяка — `entry_page_id` **32**.

**Кластеры фильтров** (ключи и человеческие названия из `filter_values` карточки):

| Кластер API | Подпись EN | Значения и id |
|---|---|---|
| `character_vision` | Elemental Type | Cryo 802 (22), Anemo 782 (20), Electro 773 (20), Pyro 729 (19), Hydro 751 (18), Geo 813 (15), Dendro 761 (13) |
| `character_weapon` | Weapons | Sword 71 (35), Catalyst 110 (28), Polearm 124 (24), Bow 95 (21), Claymore 79 (20) |
| `character_rarity` | Quality | 5-Star 2 (77), 4-Star 14 (51) |
| `character_region` | Region | Mondstadt 32 (24), Liyue 42 (22), Inazuma 53 (17), Sumeru 1422 (14), Fontaine 1432 (13), Natlan 1456 (11), Nod-Krai 4158 (9), Snezhnaya 1413 (6), Other 2437 (4) |
| `character_property` | Bonus Attributes From Ascension | ATK 550 (30), CRIT DMG 463 (22), CRIT Rate 507 (19), HP, EM, ER, бонусы урона стихий |

Фильтры в API — массив id. Логика **И** внутри запроса:

- `["802","71"]` (Крио + меч) → 7 человек: Traveler (Cryo), Odette, Skirk, Layla, Kamisato Ayaka, Kaeya, Qiqi.
- `["813","110","32"]` (Гео + катализатор + Мондштадт) → **0**. Пустое состояние на сайте есть, отдельной подписи API не отдаёт.

Карточка в сетке: круглая/квадратная иконка, имя, иконки стихии и оружия в `filter_values`. Поиск по имени в `get_entry_page_list` с `search_word` **не фильтрует** (запрос «Ayaka» вернул те же 130). Искать нужно клиентом или отдельным поиском.

Индекс страницы `aggregate/2` показывает группы вроде Liyue и хвост «数据加载中» — список подгружается порциями.

Тот же паттерн у Honkai: Star Rail: [роли](https://wiki.hoyolab.com/pc/hsr/aggregate/character?lang=zh-tw) с фильтрами «боевой атрибут / путь / редкость / лагерь» и переключателем уровня Lv1–Lv80 прямо в сетке. Для Genshin уровень в сетке не нужен: статы без артефактов мало говорят игроку.

**Что украсть у архива HoYoWiki**

- Четыре быстрых фильтра: стихия, оружие, редкость, регион. Бонус возвышения — вторичный, прятать за «ещё».
- Мгновенный отклик без кнопки «найти» (это подтверждают и разборы вики: фильтр срабатывает по клику).
- Иконка стихии на карточке — главный якорь сканирования.

**Чего избегать**

- Пятый ряд «бонус возвышения» на первом экране телефона.
- Серверный поиск, который игнорирует строку.
- `user-scalable=no`.
- Клонировать золото `#ffc805` и крем `#f0eae0` из CSS HoYoWiki: это язык офицального вишлиста, не нашего архива.

### 2.3. Карточка персонажа

Пользовательский пример `entry/10624` **сейчас не Аяка**. API и индекс отдают **Prune**: 4★ Анемо, катализатор, Мондштадт, созвездие Turris Venefica, титул Childlike Dreams Cherished. Аяка — [entry/32](https://wiki.hoyolab.com/pc/genshin/entry/31/?lang=en-us) (соседний Ayato — 31). Ниже — модули Аяки; у Prune тот же каркас.

Запрос: `GET https://sg-wiki-api-static.hoyolab.com/hoyowiki/genshin/wapi/entry_page?entry_page_id=32` с заголовком `x-rpc-language`.

**Шапка.** Имя, одно-два предложения описания, иконка, широкий `header_img`, фильтры-бейджи. Русский заголовок: «Аяка». Описание: «Наследница клана Камисато комиссии Ясиро. Благородна и изящна, мудра и сильна.»

**Модули EN → RU (как отдаёт `ru-ru`)**

| id | EN | RU | Компонент |
|---|---|---|---|
| 1 | Attributes | Характеристики | таблица имя / ДР / созвездие / титул / глаз Бога / фракция / актёры / именная карта / блюдо / версия |
| 2 | Ascend | Возвысить | статы по уровням + материалы + карта фарма |
| 3 | Gallery | Галерея | аватар, костюмы, idle-анимации, картинка созвездия |

| 5 | Constellation | Созвездие | 6 узлов: иконка, имя, эффект |
| 10055 | Video Collection | Видео | тизер, демо, miscellany, тизер костюма |
| 6 | Description | Описание | 8 глав истории |
| 7 | Voice-Over | Озвучивание | у Аяки 71 реплика, у каждой до 4 аудио |
| 27 | Additional Information | Дополнительно | пустой список |
| 34 | Weapon and Artifact Recommendations | Рекомендации по оружию, артефактам и отрядам | кастомный HTML-гайд |
| 35 | Lore | (пустое имя в RU) | интро, титул «Frostflake Heron», отношения, выжимки озвучки |
| 67 | Media | Медиа | анонсы HoYoLAB, дни рождения |

**История Аяки — уже шаги, но свалены в одну простыню**

1. Character Details / «О персонаже»
2. Character Story 1–5 / «История персонажа 1–5» (в тексте: Unlocks at Friendship Lv. 2…6)
3. Именная вещица: «Moriwakamaru» / «Моривакамару»
4. Vision / «Глаз Бога»

Это канонический набор Genshin, не выдумка вики. Стена появляется, потому что все 8 глав открыты сразу.

**Таланты Аяки в API**

1. Kamisato Art - Kabuki — обычная атака, таблица из 10 строк
2. Kamisato Art: Hyouka — навык, Skill DMG 239% на Lv.1, КД 10 с, GIF
3. Kamisato Art: Senho — альтернативный спринт (таблица на 1 уровень)
4. Kamisato Art: Soumetsu — взрыв
5. Amatsumi Kunitsumi Sanctification — пассивка возвышения 1
6. Kanten Senmyou Blessing — пассивка возвышения 4
7. Fruits of Shinsa — утилита крафта

Таблица навыка тянется на 14 колонок. Материалы в JSON часто пустые массивы — не строить UI вокруг них без своей базы.

**Созвездие** — шесть узлов с поэтическими именами (Snowswept Sakura … Dance of Suigetsu). C3 и C5 — «+3 к уровню навыка»: в гайде это скучно, в лоре — часть картины созвездия Grus Nivis.

**Галерея Аяки:** Avatar (костюм Flawless Radiance), Outfit Springbloom Missive, 4 idle, Constellation.

**Видео:** Character Teaser «The Homeward Heron», Demo «Camellia in Winter Snow», Collected Miscellany «Snowdance Heron».

**Модуль 34** — уже гайд: приоритет взрыва, инфузия после спринта, оружие 3★/4★/5★, Amenoma Kageuchi как доступный вариант. Это не лор. Это второй продукт внутри той же страницы. Наша витрина должна **развести** архив и гайд, а не склеивать их в один скролл.

**Что украсть**

- Шапка: портрет + стихия + оружие + одно предложение.
- История как нумерованные главы дружбы, не как эссе.
- Один GIF на талант, не 14 колонок сразу.
- Созвездие как 6 узлов на рисунке, не как список.

**Чего избегать**

- Все 71 реплики озвучки на карточке.
- Кастомные HTML-простыни «рекомендации» без структуры.
- Пустой блок «Дополнительно».
- Копировать порядок модулей 1→67: игрок сначала хочет роль и навык, не таблицу возвышения.

## 3. Сравнение с другими витринами

Открыты живые страницы. Где JS отдал пустышку — это сказано прямо.

### 3.1. Prydwen Institute — Wuthering Waves и Honkai: Star Rail

- Каталог WuWa: [prydwen.gg/wuthering-waves/characters](https://www.prydwen.gg/wuthering-waves/characters/) — «Showing 60 Characters», фильтры 4★/5★, стихия иконками, оружие иконками, кнопка Reset. Карточка = wish-art + имя + иконка стихии. Новые помечены «New» / номером патча.
- Каталог HSR: [prydwen.gg/star-rail/characters](https://www.prydwen.gg/star-rail/characters/) — 94 персонажа, те же иконки стихии + путь.
- Карточка Changli: [prydwen.gg/wuthering-waves/characters/changli](https://www.prydwen.gg/wuthering-waves/characters/changli) — вкладки **Kit / Review / Build / Gameplay and teams / Calculations**. Сначала короткий лор, затем навыки с подзаголовками (Basic / Skill / Liberation / Forte), множители спрятаны. Ротации — отдельные именованные списки: Opener, Standard, Double Intro, Max Potential. Команды — 3–4 портрета.
- Карточка Seele: [prydwen.gg/star-rail/characters/seele](https://www.prydwen.gg/star-rail/characters/seele) — тот же каркас: Kit → Review → Build and teams. Навык как карточка: тип (Single Target), энергия, break. Relics с процентом относительно базы. Команды с app. rate.

**Украсть:** вкладки «набор / гайд», иконки-фильтры, одна ротация = один список, команды картинками.  
**Избегать:** рейтинг T0–T4 и простыня «review» на 3000 слов на мобильном первом экране. Для русской витрины рейтинг — отдельный слой, не герой страницы.

### 3.2. genshin.gg

- Каталог: [genshin.gg](https://genshin.gg/) — три выпадающих списка: Rarity / Element / Weapon. Сетка портретов, стихия бейджем, метка NEW.
- Карточка Аяки: [genshin.gg/characters/ayaka](https://genshin.gg/characters/ayaka/) — сверху материалы и топ оружия/артефактов **до** лора. Вкладки Showcase / Teams / Talents / Passives / Constellations / Ascension. Команды — 4 портрета с подписью «Ayaka Freeze». Таланты — иконка + имя + абзац, без таблицы 14 уровней.

**Украсть:** гайд-сводка над лором для игрока «хочу собрать». Команды как ряд лиц.  
**Избегать:** три `<select>` вместо иконок стихий — на телефоне хуже сканируются. Нет региона. Нет истории.

### 3.3. KeqingMains

- Полный гайд: [keqingmains.com/keqing](https://keqingmains.com/keqing/)
- Быстрый гайд Аяки: [keqingmains.com/q/ayaka-quickguide](https://keqingmains.com/q/ayaka-quickguide/) (страница открылась, тело — заголовок; структура полного гайда Аяки подтверждена индексом [keqingmains.com/ayaka](https://keqingmains.com/ayaka/))

Паттерн KQM: **приоритет талантов первым** («Burst > Normal Attack > Skill»), затем разбор каждого таланта человеческим языком, затем сеты с процентом DPS, затем ротация в нотации `EQE N1C`. Команды сгруппированы по архетипу (Aggravate, Overload, Freeze).

**Украсть:** приоритет талантов одной строкой; ротация как код с расшифровкой; один архетип = один шаг.  
**Избегать:** нотацию без легенды; калькуляции «104% of best 2pc» как главный экран. Это язык теориикрафта, не витрины.

### 3.4. Honey Hunter World

Живой `genshin.honeyhunterworld.com/ayaka_002/?lang=EN` закрыт Cloudflare («Just a moment…»). Индекс открытых карточек (Mavuika, Venti, Traveler) даёт оглавление:

Stats → Skills → Skill Ascension → Related Items → Gallery → Sounds → Quotes → Stories.

Навыки — широкая таблица Lv1–Lv15. История и цитаты — в конце. Это **база данных**, не витрина.

**Украсть:** полнота данных где-то в слое «ещё».  
**Избегать:** таблицу 15 уровней по умолчанию; домашнюю страницу как расписание доменов.

### 3.5. League of Legends — геймплей vs лор

- Геймплей Ahri: [wiki.leagueoflegends.com/en-us/Ahri](https://wiki.leagueoflegends.com/en-us/Ahri) — инфобокс (роль, сложность, статы), затем **четыре способности как карточки**: стоимость, откат, дальность, краткое «Active:», потом Notes. Скины — визуальный ряд, не текст.
- Лор: живой HTML `universe.leagueoflegends.com/en_US/champion/ahri` пустой. Рабочая биография: [Pantheon — Scroll to Begin](https://universe.leagueoflegends.com/en_US/story/champion/pantheon/). Титул + эпитет, затем длинный скролл-рассказ, в конце «Read Pantheon's story».

- Wiki-лор Ahri: [Universe:Ahri](https://wiki.leagueoflegends.com/en-us/Universe:Ahri) — оглавление Early Life → Modern History → Recent Events → Appearance → Personality → Abilities → Relations. Это **шаги**, но слишком глубокие для нашей витрины.

**Украсть:** short bio на карточке; способность = карточка с 3 числами; лор как «листай главы», не как вики-оглавление на 16 пунктов.  
**Избегать:** все скины; все отношения; заметки про баги способностей.

### 3.6. FINAL FANTASY XIV Job Guide

Живая страница: [na.finalfantasyxiv.com/jobguide/paladin](https://na.finalfantasyxiv.com/jobguide/paladin).

### 3.7. Dota 2

`https://www.dota2.com/hero/juggernaut` и `/heroes` в fetch — только заголовок (SPA). ## 4. Информационная архитектура

### 4.1. Каталог

**Фильтры первого экрана (мультивыбор внутри кластера, между кластерами — И)**

1. Стихия — 7 иконок.
2. Оружие — 5 иконок.
3. Редкость — 4★ / 5★.
4. Регион — 8 + «другой».

Поиск по имени — клиентский, над сеткой, плейсхолдер «имя персонажа». Счётчик: «24 из 130». Кнопка «сбросить» появляется только если фильтр не пуст.

Бонус возвышения и сортировка (новые / имя / редкость) — в «ещё», не на первом экране.

**Сортировка по умолчанию.** Как у HoYoWiki: новые сверху. Игрок приходит «кто вышел». Алфавит — опция.

### 4.2. Страница персонажа — модель шагов

Не вкладки-близнецы HoYoWiki. Один вертикальный ритуал из пяти шагов. Активный шаг занимает экран. Соседние видны как «нить созвездия».

```
Шаг 1  Обзор
Шаг 2  История
Шаг 3  Набор
Шаг 4  Созвездие
Шаг 5  Гайд
```

Нумерация здесь уместна: это **последовательность знакомства**, не декор. Frontend-design skill разрешает 01/02, когда порядок несёт смысл.

**Шаг 1. Обзор** — портрет виша, имя, титул, стихия, оружие, регион, одно предложение, три факта (роль в бою, стоимость взрыва, «сложность пальцев»). Кнопка «к гайду» для тех, кто уже знает лор.

**Шаг 2. История** — см. раздел 5.

**Шаг 3. Набор** — см. раздел 7.

**Шаг 4. Созвездие** — картинка созвездия + 6 узлов. C1 выбран по умолчанию. C3/C5 помечать «уровень навыка», не прятать.

**Шаг 5. Гайд** — вложенные шаги, см. раздел 8.

Возвышение, материалы, озвучка, медиа — не шаги. Ссылки «материалы» и «видео» в подвале шага 1.

## 5. Как подать историю шагами

Канон Genshin уже режет лор на 8 кусков. Витрина показывает **один кусок**.

**Порядок чтения Аяки (как в API, не выдумывать свой)**

1. Кто она при дворе.
2. Ясиро и бремя комиссии.
3. Юность среди интриг.
4. Старая песня / встреча с городом.
5. Быт «принцессы».
6. Искусства и характер.
7. Моривакамару — тёплая вещица.
8. Глаз Бога.

Подпись шага — человеческая, не «История персонажа 3».

Примеры строк:

- «Кто такая Аяка»
- «Дом Камисато»
- «Девочка при дворе»
- «Песня во дворе»
- «Как живёт принцесса»
- «Чай, меч, долг»
- «Моривакамару»
- «Глаз Бога»

**Правила набора**

- Один абзац 2–4 предложения на шаг. Полный текст главы — «читать целиком».
- Не писать «открывается на уровне дружбы 4» канцеляритом. Если показываем канон: «глава открывается на дружбе 4».
- Цитата персонажа — один блок, не лента из 71 реплики. Для Аяки достаточно «Hello» и одной «Chat: Sword».
- Связи (Тома, Аято) — три чипа с портретом, не таблица voice-over.

**Чего не делать.** Не склеивать 8 глав в статью. Не ставить лор после таблицы возвышения. Не спойлерить Архонтский квест в шаге 1.

Короткий bio на обзоре — как Riot short bio: 80–100 слов, «зачем играть этой фантазией». Полные главы — шаг 2.

## 6. Как рисовать витрину

### 6.1. Карточка в сетке

Форма — **вишлист-карта**, не квадрат маркетплейса.

```
┌─────────────────┐
│  foil frame     │
│   wish splash   │  ← портрет по пояс, небо региона
│  ★★★★★  cryo   │
│  Аяка           │
│  меч · Инадзума │
└─────────────────┘
```

- 5★ — тонкая фольга `#D4B56A`. 4★ — холодный серебряный кант `#8A93B0`.
- Стихия — маленький глаз Бога в углу, не радуга градиентов на всю карточку.
- Имя — El Messiri, одна строка. Длинные имена («Камисато Аяка») на карточке укорачивать до «Аяка», полное — в шапке.
- Сетка: 2 колонки < 768px, 3 на планшете, 4–5 на десктопе. Не masonry и не «bento ради бенто».

**Hover / focus (только pointer: fine)**

- Карта поднимается через `transform: translateY(-4px)`.
- По портрету проявляется схема созвездия (линии, не текст).
- Не scale(1.05) на всю сетку — соседние карты прыгают.

**Клавиатура.** Фокус — кольцо фольги. Enter открывает персонажа.

### 6.2. Сканирование

Игрок ищет **цвет стихии**, потом силуэт оружия, потом имя. Поэтому:

- Фильтры-иконки липнут под шапкой на мобиле (`position: sticky`, без `backdrop-blur` на всей сетке).
- Активный фильтр — заливка цвета стихии, не серый чип.
- Счётчик всегда виден: «7 персонажей · крио · меч».

### 6.3. Состояния

| Состояние | Что видит человек |
|---|---|
| Загрузка | 8 скелетов карт той же пропорции, без спиннера на весь экран как у HoYoWiki |
| Пустой фильтр | «Такой комбинации в архиве нет.» «Сбросьте стихию или оружие.» Кнопка «сбросить фильтры» |
| Нет поиска | «Имени нет в архиве.» «Проверьте написание. Пишите по-русски или латиницей.» |
| Ошибка сети | «Архив не загрузился.» «Повторить» |
| Новый персонаж | тонкая метка «новый» на карте, не баннер |

Пустой Geo + катализатор + Мондштадт — реальный кейс HoYoWiki (0 записей). Текст не извиняется.

### 6.4. Мобильное поведение каталога

- Фильтры: горизонтальный ряд иконок, свайп, не аккордеон на три этажа.
- Поиск всегда в шапке.
- Карта — минимум 44px по имени-кнопке.
- Не фиксировать высоту `h-screen`. `min-h-[100dvh]` только у героя персонажа.

## 7. Таланты и способности без перегруза

Экран набора — **панель из четырёх слотов**, как у Dota, не простыня Honey Hunter.

```
[НА] [E] [спринт] [Q]
        ★ выбран E
┌ превью GIF / первый кадр ┐
│  Хёка                     │
│  КД 10 с · частицы        │
│  два предложения «зачем»  │
│  [числа навыка]           │
└───────────────────────────┘
пассивки — отдельная полоса из трёх иконок
```

**Правила**

1. По умолчанию открыт **элементальный навык** (E), не обычная атака. У Аяки урон живёт во взрыве — тогда дефолт Q. Правило: открывать талант, который гайд ставит первым в приоритете.
2. GIF автоплей только если `prefers-reduced-motion: no-preference` и карточка в вьюпорте. Иначе статичный кадр.
3. Таблица множителей — внутри «числа навыка», колонки Lv. 1 / 6 / 9 / 10, не 1–14.
4. Пассивки: одна строка «после E обычные бьют сильнее 6 с» — человеческий язык, потом канон.
5. Утилита крафта (Fruits of Shinsa) — сноска, не слот рядом с Q.

**Карточка способности занимает три слоя** (урок LoL):

1. Имя и роль в бою.
2. Что нажать и что произойдёт.
3. Числа и оговорки.

Не мешать слои. Игрок, которому нужен только «зачем», не должен видеть 239%.

Русские подписи слотов: «удар», «навык», «взрыв», «спринт». Не «Ешка», не «ульта».

## 8. Пошаговый гайд

Гайд — **второй ритуал**, вложенный в шаг 5. Пять шагов, один экран каждый.

```
1 роль
2 оружие
3 артефакты
4 отряд
5 ротация
```

### Шаг «роль»

- Одна фраза: «Аяка держит поле и замораживает.»
- Приоритет талантов: «взрыв → удар → навык» (KQM).
- Сложность: «нужен спринт перед ударом».
- Не тир.

### Шаг «оружие»

- Три слота: «лучшее», «доступное», «без крутки».
- У Аяки доступное — Amenoma Kageuchi (это пишет даже модуль 34 HoYoWiki).
- Одно предложение «почему», не пассив целиком.

### Шаг «артефакты»

- Один основной сет (4 предмета) + запасной 2+2.
- Пески / кубок / корона одной строкой.
- Субстаты одной строкой.
- Не сравнительная таблица на 12 сетов.

### Шаг «отряд»

- Две готовые четвёрки портретами.
- Подпись архетипа: «заморозка», «моно крио».
- Кто на поле, кто бьёт с кармана — четыре слова на портрет.

### Шаг «ротация»

- Нумерованный список из 4–7 действий.
- Рядом легенда: E навык, Q взрыв, спринт, удар.
- Нотацию `EQE N1C` показывать только после легенды, мелким моноширинным.
- Один «простой» цикл. «Сложный» — раскрытие.

**Тон гайда.** Выгода читателя, короткие фразы. Не «рекомендуется использовать». Не «оптимальный ротейшен».

Примеры строк интерфейса:

- «С чего начать в бою»
- «Какое оружие надеть»
- «Какой сет фармить»
- «С кем поставить»
- «Порядок навыков»

Кнопка в конце: «к набору» — вернуться к GIF навыка. Один призыв.

## 9. Визуальный контракт

Тема: **ночной архив Тейвата**. Карты желаний, линии созвездий, цвет глаза Бога. Не крем с терракотой, не кислотный неон на чёрном, не газетная вёрстка.

### Цвет (6 токенов)

| Токен | Hex | Роль |
|---|---|---|
| `void` | `#070B18` | небо архива, фон |
| `tray` | `#141C34` | лоток карты, панели |
| `moon` | `#C9D4EE` | основной текст |
| `foil` | `#D4B56A` | 5★, заголовки, фокус |
| `frost` | `#8EC8E0` | ссылки, активный фильтр по умолчанию |
| `ember` | `#C45C4A` | ошибка, предупреждение |

Стихии — отдельные токены поверх контракта, не вместо него:

- Анемо `#6EC5B8`
- Гео `#E0C36A`
- Электро `#B78BFF`
- Дендро `#7BBF6A`
- Гидро `#4C8ED9`
- Пиро `#E06A4C`
- Крио `#8EC8E0` (= `frost`)

Не использовать офицальный вишлист `#ffc805` как бренд. Наша фольга теплее и тише.

Поверхность карты: внешний лоток `tray` + внутреннее поле `#0E1530` + волосяное кольцо `foil` на 12% непрозрачности. Вложенная рамка — да. Серый `1px #ccc` — нет.

### Шрифты

Запрет: Inter, Roboto, Arial, Open Sans, Helvetica.

| Роль | Гарнитура | Зачем |
|---|---|---|
| Имена, шаги, титулы | **El Messiri** | рукопись Тейвата, есть кириллица, не «кремовый серф по умолчанию» |
| Текст, UI | **Onest** | геометрический гротеск с кириллицей, не Inter |
| Числа талантов, ротация | **IBM Plex Mono** | таблицы множителей, легенда E/Q |

Масштаб: имя персонажа 32–40px на мобиле, шаг 13px трекингом, тело 16–17px, подпись 12px. Не делать display на каждой карточке сетки — только имя.

### Сигнатура

**Созвездие как стекло архива.** На карточке в сетке при наведении проступают линии созвездия персонажа. На шаге «созвездие» те же линии — карта неба, узлы нажимаются. Это не декор: это навигация по C1–C6.

Один риск, вокруг — тишина. Ни зерна на скролле, ни mesh-орбов, ни «bento из 7 плиток».

### Движение

Кривая: `cubic-bezier(0.32, 0.72, 0, 1)`, 280–500 мс. Только `transform` и `opacity`.

- Смена шага: линия созвездия дорисовывается до следующей звезды.
- Смена таланта: превью кроссфейд.
- Карта: подъём 4px.
- `prefers-reduced-motion: reduce` — мгновенная смена, линии статичны.

Не ставить `backdrop-blur` на сетку. Блюр — только у липких фильтров, если без него не читается.

### Мобильный каркас персонажа

```
[← архив]     Аяка     [шаг 3/5]
──────●──●──●──○──○────  нить шагов
портрет на фоне ночи
контент шага
[назад]              [дальше]
```

Нить шагов — не точки пагинации приложения. Это созвездие. Подпись текущего шага текстом, не только точкой.

## 10. Anti-slop: чего не выпускать

- Шрифты Inter / Roboto / «нейросетевой» крем `#F4F1EA` + терракота.
- Чёрный фон + кислотный зелёный.
- Газетные линейки и три колонки бродшита.
- Нумерация 01/02 на фильтрах каталога (это не процесс).
- Sticky-шапка на всю ширину с логотипом, приклеенная к верху.
- Lucide/Material иконки толстой обводкой. Стихии — глаза Бога, оружие — силуэты из игры.
- Серые границы 1px и `shadow-md`.
- `ease-in-out` по умолчанию, анимация `width`/`height`.
- Скелет «Welcome to HoYoWiki» на 100vh.
- Тир SS/T0 на герое страницы.
- Стена модулей HoYoWiki в том же порядке.
- Английские «DPS», «ER req», «rotation» в UI. Можно в легенде ротации после русского.
- Сленг: «ульта», «ешка», «крутить», «имба».
- Канцелярит: «осуществляется нанесение урона», «данному персонажу рекомендуется».
- «Лучший», «самый сильный» без оговорки. Писать «часто берут в заморозку».
- Автовоспроизведение трёх GIF сразу.
- Карточки без портрета («скоро» серым квадратом).
