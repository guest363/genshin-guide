# Викторина: материалы для вопросов

Собрание проверенных фактов, пригодных для тестов по игре. Составлено для
раздела «Викторина» (маршрут `/victorina`): банки вопросов по регионам,
персонажам, монстрам, истории и механикам.

## Источники

1. **Дамп персонажей** — `research/characters/*.md` (120 файлов, JSON-заголовки
   из официальных строк архива HoYoverse, дамп Yatta + русская вики Fandom).
   Поля, годные для вопросов: `name`, `nameEn`, `title`, `element`,
   `elementLabel`, `weapon`, `weaponLabel`, `region`, `regionLabel`, `rarity`,
   `constellation`, `affiliation`, `archon`, `role`, `birthday`.
2. **Кодекс реакций** — `src/lib/reactions.ts`. Русские названия сверены с
   дампами талантов из `research/characters` (см. комментарий в шапке файла).
   Самый надёжный источник по реакциям — брать названия дословно из него.
3. **Референс викторины** — `examples/Архив Тейвата/` (25 вопросов по лору с
   уровнями 1–5, источниками Fandom; дизайн не наш, контент — отправная точка).
4. Общеизвестный сюжет игры до версий 6.x; сомнительные и спорные детали сюда
   не включены.

## Стихии

Семь основных: **Анемо, Гео, Электро, Дендро, Гидро, Пиро, Крио**.
Восьмая условная — «адаптивная» стихия Путешественника (резонирует со Статуями
семи Архонтов и не нуждается в Глазе Бога).

## Реакции (официальные RU-названия, из `src/lib/reactions.ts`)

| Пара | Название | Суть |
| --- | --- | --- |
| Гидро+Пиро | **Пар** | усиление ×2, если бьёт Пиро, ×1,5 — если Гидро |
| Крио+Пиро | **Таяние** | усиление ×2, если бьёт Пиро, ×1,5 — если Крио |
| Пиро+Электро | **Перегрузка** | взрыв Пиро по площади |
| Гидро+Электро | **Заряжен** | разряд цепью; обе ауры сосуществуют |
| Гидро+Крио | **Заморозка** | цель скована льдом; снимают Пар и «Разбит» (физ. урон) |
| Крио+Электро | **Сверхпроводник** | снижает физическое сопротивление |
| Дендро+Пиро | **Горение** | непрерывный урон Пиро |
| Гидро+Дендро | **Цветение** | рождается ядро цветения (на поле до 5) |
| Дендро+Электро | **Стимуляция** | цель пробуждена к Обострению и Разрастанию |
| Анемо+стихия | **Рассеивание** | стихия разнесена по площади (Анемо ауры не оставляет) |
| Гео+стихия | **Кристаллизация** | кристалл-щит (Гео ауры не оставляет) |

Ядра цветения перехватывают Электро и Пиро раньше аур:
**Вегетация** (Электро по ядру — побег-стрела, тратит одно ядро),
**Бутонизация** (Пиро по ядру — взрывает все ядра разом).

Пробуждённая цель: Электро-удар — **Обострение**, Дендро-удар — **Разрастание**;
пробуждение сохраняется.

Семейства 6.x: пассивки «**Лунное знамение**» включают лунные реакции
(«Лунный заряд», «Лунная бутонизация», «Лунный кристалл», «Гармония Лунной
пелены», роса «Зелёная роса»), пассивки «**Звёздный блеск**» — звёздные
(«Звёздный проводник», «Звёздное рассеивание» с звёздным вихрём). Оба знака
могут стоять одновременно.

## Игровые механики

- Первородная смола: 1 единица восстанавливается **8 минут**.
- Еженедельные боссы: первые **три** награды в неделю стоят 30 смолы вместо 60.
- Стандартный внутренний откат наложения стихии: **3 удара или 2,5 секунды**.
- Путешественник — единственный, кто меняет стихии без Глаза Бога.
- Рассеивание распространяет только Пиро, Гидро, Электро и Крио; Анемо и Гео
  сами аур не оставляют.

## История (хронология, безопасные факты)

1. До Первозданного элементальным миром правили **Семь Драконов-владык**.
2. **Первозданный** (возможно, Фанет) победил драконов и создал четыре сияющие
   тени; над миром встали солнце и луна.
3. **Война Архонтов** — эпоха борьбы за семь тронов.
4. **Каэнри’ах** — государство без бога; пал в **Катаклизме ~500 лет** до
   начала путешествия. Хиличурлы — проклятые жители Каэнри’аха.
5. Инадзума: Указ об охоте на Глаза Бога — часть стремления сёгуна к вечности.
6. Сумеру: Великая властительница **Руккхадевата** удалена из Ирминсуля — мир
   приписал её деяния Нахиде.
7. Фонтейн: **Фокалорс** казнила собственную божественность и трон Гидро,
   полнота власти вернулась **Нёвиллету** — фонтийнцы стали настоящими людьми.
8. **Сошедшие** (вне мира Тейвата): Путешественник — **Четвёртый**; близнец
   записан в Ирминсуле как принадлежащий Тейвату. Сердца Бога, по словам
   Скирк, сделаны из останков **Третьего Сошедшего**.
9. Энканомия до Ватацуми называлась **Бякуякоку** («страна белой ночи»).
10. Древние царства: **Рем** правил Ремурией; Алый король пустыни — царь
    **Дешрет** (также Амон).

## Персонажи (что брать из дампа)

- «Кто такой по титулу / региону / стихии / оружию / созвездию / организации» —
  прямые вопросы из полей файла.
- **Архонты** — флаг `archon: true` (семеро: Вэнти, Чжун Ли, Райдэн, Нахида,
  Фокалорс→Нёвиллет, Мавуика, Царица-неиграбельна — флаг стоит только у
  играбельных).
- Пояснение к ответу собирается из полей: титул, редкость, стихия, оружие,
  регион, созвездие, принадлежность.

## Монстры

- **Фатуи** подчиняются **Царице** из Снежной; во главе ударных агентов —
  **Одиннадцать Глашатаев**. Тарталья (Чайльд) — **Одиннадцатый** Глашатай,
  Дотторэ — **Доктор**.
- **Маги Бездны** повелевают Пиро, Гидро, Крио и Электро; щит снимает
  соответствующая реакция.
- **Ордо Бездны** управляет хиличурлами; его принцесса — близнец
  Путешественника.
- **Хиличурлы** — проклятые жители Каэнри’аха; крупные вожаки с дубинами —
  **Митачурлы**.
- **Двалин**, он же Ужас Бури, — дракон Мондштадта, первый еженедельный босс.
- **Андриус**, великий волк севера, испытывает путников в Волчьем поместье.
- **Океанид** — Гидро-элементаль из Лухуа (Ли Юэ), создаёт водных мимикров.
- Древние боевые машины в руинах — наследие **Каэнри’аха**.
- **Спектры** — летающие стихийные духи, впервые появились в Инадзуме.
- **Маг Цицин** (Фатуи) сражается призываемыми цицинами.

## Формат вопроса

- 4 варианта, ровно один верный; неверные — правдоподобные, из той же категории.
- Обязательное подробное пояснение (1–3 предложения) — показывается в разборе.
- Сложность 1–3: 1 — общеизвестное, 2 — нужно играть/читать, 3 — глубокий лор.
- Атtempt собирается из банка случайно (10 вопросов), варианты перемешиваются.
