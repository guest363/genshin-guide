# Дизайн сайта: как устроен визуальный язык

Памятка для новых страниц и компонентов. Составлена по `src/styles/*` и
готовым страницам (каталог, персонаж, реакции) перед работой над викториной.

## Палитра (`src/styles/tokens.css`)

- Фоны: `--ink #070b18` (корень), `--abyss #10182a`, `--panel #141c2e`,
  `--panel-inner #0c1220`. Страницы почти всегда прозрачны над фоном body;
  панели красят композитом: `linear-gradient(180deg, rgb(255 255 255 / 4%),
  rgb(255 255 255 / 1%)), #0a0f1b` + бордер `--line`.
- Текст: `--moon #e7edf7` (основной), `--mist #9aa8c2` (вторичный),
  `--frost #8ec8e0` (холодный акцент).
- Металл: `--gilt #d4b56a` (золото-акцент, ссылки, кикеры), `--gilt-dim`.
- Линии: `--line` = `rgb(224 196 138 / 22%)` — золотая прозрачная нить.
- Ошибки: `--danger #d9786a`. Успеха в токенах нет — вводить локально
  (например, `#7ac9a2`) в CSS-модуле раздела.
- Стихии: `--pyro --hydro --anemo --electro --dendro --cryo --geo --adaptive`.
- Радиусы: `--radius-shell 1.75rem` (оболочки), `--radius-inner 1.35rem`,
  пилюли `border-radius: 999px`. Тень: `--shadow-card`.
- Отступы `--space-xs…xl`; движение `--ease` (обнуляется при
  `prefers-reduced-motion`).

## Типографика

- Дисплейный шрифт `--font-display` (Unbounded) — заголовки страниц и
  карточек, `letter-spacing: -0.02em`, размер `clamp(1.9rem, 4.5vw, 2.9rem)`.
- Текст `--font-body` (Onest), база 1rem/1.55.
- Кикер: `--gilt`, `0.68rem`, `letter-spacing: 0.18em`, uppercase — над
  заголовками и в подписях секций. Кикер ≠ заголовок (не дублировать текст).
- Хлебные крошки в липкой шапке: uppercase, `letter-spacing: 0.12em`,
  `--mist`.

## Анатомия страницы (паттерн «реакций»)

1. `.page`: `width: min(1180px, calc(100% - 1.5rem)); margin: 0 auto;
   padding: 1.1rem 0 4rem; display: grid; gap: 1.6rem`.
2. Липкая шапка-пилюля `.bar`: `position: sticky; top: 0.55rem; z-index: 30;
   border: 1px solid var(--line); border-radius: 999px;
   background: rgb(8 12 22 / 84%); box-shadow: var(--shadow-card)`.
   Слева ссылка «← Архив» (пилюля с фоном `color-mix(in srgb, var(--gilt)
   14%, transparent)`), справа крошка-название раздела.
3. `.head`: заголовок `h1` + лид `--mist` (максимум ~46rem).
4. Контентная сетка; сайдбар на десктопе ~21rem, на мобиле — одна колонка.

Фоновая аура: `<ElementAura element="…" />` из `components/element-aura` —
canvas-сцена на весь экран; на телефонах приглушается до `opacity: 0.6`.

## Компоненты-образцы

- `ArchiveHeader` — астролябия (SVG-орбиты с искрами семи стихий + звезда),
  брэнд «Архив Тейвата», счётчик архива, ссылки на разделы (`.ledger`).
- `CharacterCard` — сетка каталога: портрет, gilt-рамка, бейдж звёзд, печати
  архонта (`components/archon-sign`), ховер-подъём.
- `FilterBar` — группы фильтров-чипов, состояние в URL (`useSearchParams`).
- `ReactionArena` — интерактивная плита; листинг кодекса — `entry`-строки с
  цветными точками стихий, `data-lit` подсветка золотом.

## Движение и доступность

- Все переходы через `--ease`, 0.2–0.4 s; `prefers-reduced-motion` гасит
  анимации (и в токенах, и в сценах ауры).
- `:focus-visible` — обводка `var(--gilt)`, offset 3px (задан в `base.css`).
- Хит-зоны кнопок ≥ 40px; aria-метки на иконках; навигация по карточке —
  паттерн `CharacterNav` (burger, Escape, клик вне).

## Мобильные правила (выстраданные)

- Липкая шапка компактная; на телефонах не занимать экран — можно
  скрывать подписи, оставляя брэнд.
- Аура-фон на телефонах приглушать: фон лежит под текстом.
- Не перекрывать контент плавающими плитами.
- Смотри коммиты: `mobile lab`, `mobile character nav` — полное
  обёрточное полотно вместо inset-подхода.

## Чего не делать

- **Не вешать `preserve-3d` на обёртки с ховером** — ломает hit-test,
  pointerleave циклится (см. память проекта).
- **Не обрезать текст «…»** — вместо этого сворачивать (стандарт UI).
- **Не дублировать заголовок кикером** — кикер это категория, не повтор.
- Не хранить второй набор фактов: данные читаются из `research/` напрямую.
- Не использовать цвета вне палитры (кроме локальных семантических
  вроде «верно/неверно» внутри CSS-модуля раздела).
